# Competitive Watch — SIH26017 (2026-09)

Current public GitHub search shows multiple SIH26017 implementations. The strongest benchmark inspected for this checkpoint is `Ujjwal160107/adhigrahan-radar`, which combines staged risk scoring, court-to-parcel linkage, ingestion and a large test suite. Another current public implementation, `ekkerihasan/Landwatch`, explicitly labels its data/model synthetic and positions the product as a decision-support layer. These are benchmarks, not source material to copy.

BHOOMIDHRISTI differentiation remains: prediction → evidence → decision → assigned action → measured outcome; authority-aware access; provenance; statutory rules separated from ML; government-system-of-record boundary; and controlled learning.

Official DoLR currently publishes DILRMP 3.0 Operational Guidelines (2026–2031).
