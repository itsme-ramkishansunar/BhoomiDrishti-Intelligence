# BHOOMIDHRISHTI U75.2–U75.4 Bulk Intelligence Release

Version: `1.0.24-u75.2-4-bulk-intelligence`

## Scope

This release extends the U75.1 governed bulk integration baseline with four connected layers:

1. **U75.2 Governed Action Intelligence**
   - deterministic recommendation rules separate from prediction
   - portfolio preview
   - bulk recommendation generation
   - duplicate suppression
   - owner/severity/priority/evidence metadata
   - backend `workflow:action` enforcement
   - Operations Center + Project Intelligence surfaces

2. **U75.3 Governed What-if Scenarios**
   - server-side scenario calculation using the existing transparent risk engine
   - actual project state is cloned; project facts are never mutated
   - scenario persistence through the existing `interventions` model
   - explicit hypothetical/scenario disclaimer
   - Project Intelligence scenario history

3. **U75.4 Configured Timeline Intelligence**
   - reads existing `project_stages`
   - compares configured target days with recorded elapsed days
   - exposes active-stage variance and configured-clock status
   - does not invent statutory deadlines
   - portfolio timeline endpoint + Operations Center

4. **Bulk public-source snapshot orchestration**
   - administrator-only bulk capture of configured public connector snapshots
   - records success/failure individually
   - preserves the distinction between public snapshot and authoritative government data
   - does not automatically promote snapshots into project truth

## Database safety

No new database migration is required by this release.

The implementation reuses:
- `recommendations`
- `interventions`
- `intervention_actions`
- `project_stages`
- `project_events`
- existing connector snapshot tables

No destructive reset/drop/reseed operation is introduced.

## Governance boundaries

- Recommendations are workflow signals, not legal determinations.
- Scenarios are hypothetical and not future-outcome predictions.
- Timeline status is based only on configured clocks and recorded events.
- Public HTTP success does not establish an authorized government API or authoritative government record.
- Predictive Lab production promotion remains governed/blocked until existing ML evidence gates are satisfied.
