# BHOOMIDHRISHTI U72.3 — Multilingual Intake Accuracy Hardening

U72.3 is a safe accuracy hardening layer over U72.2. It does not replace the predictive model, GIS, authentication/RBAC, SQLite store, or production governance.

## Fixed from real Marathi acquisition-award regression
- Avoids falsely listing related Devanagari languages such as Konkani, Hindi, Dogri, Maithili and Nepali when the evidence only supports Marathi.
- Extracts project name `Nashik Ring Road` from English proper-name evidence embedded in Marathi documents.
- Normalizes OCR variants for Maharashtra, Nashik, Dindori and Manori.
- Extracts Marathi/Devanagari civil-suit numbers such as 235/2008 and 22/2008.
- Extracts acquisition schedule group/survey identifiers including 111/2, 111/3, 111/4, 104, 105, 123/अ, 123/ब/1 and 137/अ.
- Deduplicates repeated statutory references instead of reporting every repeated citation as a new notification.
- Preserves source excerpts and candidate status; no extracted fact is silently promoted to an authoritative project record.

## Safety
- No database migration.
- No model replacement.
- No canonical overwrite.
- OCR remains fallback-only for image/scanned pages.
- Multilingual support remains India-wide across the 22-language layer.
