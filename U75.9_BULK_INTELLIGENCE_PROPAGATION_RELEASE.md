# U75.9 — Bulk Intelligence Propagation

Version: `1.0.29-u75.9-bulk-intelligence-propagation`

## Purpose

U75.9 connects governed bulk promotion to the downstream decision-support stack without replacing U74/U75.8 modules.

Pipeline:

`bulk promotion → project bootstrap → unified snapshot → bulk feature registry → candidate risk → early warning → action intelligence → statutory timeline → intervention intelligence → dashboard/GIS/project drilldown`

## New contracts

- `backend/domain/u75.9-bulk-intelligence.js`
  - provenance states: OBSERVED / DERIVED / FORECAST / SIMULATED / UNAVAILABLE
  - descriptive risk velocity from stored candidate predictions
  - deterministic intervention prioritisation
  - unified downstream intelligence envelope
  - bulk summary

## New administrator APIs

- `GET /api/admin/u75/bulk/intelligence`
- `POST /api/admin/u75/bulk/intelligence-refresh`
- `GET /api/admin/u75/bulk/intelligence/export.csv`

All require `workflow:admin`.

## Safety

- No persistent production database is bundled or reset.
- No destructive migration is introduced.
- Existing U75.8 safe promotion remains authoritative for conflict handling.
- Existing non-empty project values remain governed by the prior promotion path.
- Candidate predictive outputs remain non-production and uncalibrated.
- Scenario/simulation semantics remain separate from observed project facts.
- Government/public connector status is not changed by this release.
