# U75.5 — Evidence Intelligence & Safe Source Promotion 2.0

Version: `1.0.25-u75.5-evidence-promotion`

## Scope

U75.5 completes the governed bulk-data loop without silently overwriting existing project values.

`receive → profile → validate → match → field evidence → conflict review → safe promotion → feature refresh → risk/alerts/operations`

## New backend capabilities

- Additive migration `020_bulk_evidence_promotion.sql`.
- Persistent `bulk_promotion_batches` ledger.
- Persistent field-level `bulk_promotion_evidence` ledger.
- `GET /api/admin/u75/bulk/evidence/:runId`.
- `POST /api/admin/u75/bulk/safe-promotion-preview`.
- `POST /api/admin/u75/bulk/safe-promote`.
- Field-level decisions record incoming value, existing value, source/checksum, match state, confidence and decision.
- Conflict policy is `KEEP_EXISTING`: a non-empty existing value is never replaced by an incoming conflicting value.
- Explicit conflict acknowledgement is required before a conflicting row can proceed through the safe path.
- Successful promotion continues through project bootstrap, unified-data snapshot refresh and bulk feature initialization.
- All promotion actions are audited.

## Interactive UI

Data Integration Center now provides:

- bulk public connector sync control;
- safe promotion preview;
- selectable rows;
- explicit conflict acknowledgement;
- visible `KEEP EXISTING` state;
- field-level evidence ledger;
- post-promotion evidence refresh;
- persistent provenance/checksum visibility.

## Safety

This upgrade is additive. It does not reset, drop, reseed or migrate existing project facts destructively. Predictive production promotion remains separately governed and blocked until its existing governance requirements are satisfied.
