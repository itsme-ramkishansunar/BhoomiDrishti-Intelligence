# U75.8 — Governed Bulk Workbench

Version: `1.0.28-u75.8-governed-bulk-workbench`

## Purpose

U75.8 hardens the existing U75.7 ingestion/promotion pipeline into a resumable, interactive governed workbench without resetting or replacing the persistent project database.

## Interactive bulk capabilities

- Resume the latest persisted promotion batch for the selected ingestion run.
- Browse persisted promotion batches and evidence after a page refresh.
- Filter evidence by row, field, project, source, or value.
- Filter evidence by decision state.
- Record append-only field-level review decisions with RBAC and audit metadata.
- Protect non-empty existing project values from overwrite; the Apply control is disabled when it would overwrite an existing value.
- Select all conflict-free rows or clear promotion selection.
- Export the current field-level evidence ledger to CSV.
- Open promoted projects directly from the propagation result.
- Open promoted projects directly in the interactive GIS.
- Sync individual public connectors as well as the existing Sync all action.
- Preserve U75.7 resilient in-process forensic analysis and failed-run retry/diagnostics.

## Governance

- Review decisions are evidence records; they do not silently mutate canonical project data.
- Promotion remains an explicit administrator action.
- Conflicts require explicit acknowledgement and preserve existing non-empty values.
- Predictive production promotion remains separately governed and blocked without authorised historical outcome evidence and calibration gates.
- Public connector snapshots remain non-authoritative.
- No destructive DB reset, reseed, or replacement is included.

U75.8 smoke checks and the U75/U74/U73 regression chain pass in the source environment. A fresh Vite production build must still be run on the Windows machine after dependency installation because this packaging environment does not contain `node_modules`.
