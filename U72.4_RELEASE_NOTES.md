# U72.4 — Bulk governance hardening

- Added additive project `responsible_department` ownership metadata.
- Added scoped `projects:archive` authority for Administrator, Government Officer and Department Officer profiles.
- Department Officers are restricted to their assigned state/district/project scope and matching responsible department when a project department is recorded.
- Project removal is recoverable soft-archive only; evidence/history remain preserved and a removal reason is mandatory.
- Added portfolio archive/restore controls to the project register.
- Added persistent intake field-review queue with verify/reject actions for accounts holding `documents:verify`.
- Added multilingual regression fixtures for Marathi, Hindi, Tamil and Bengali using controlled test strings; these are not government data.
- No predictive model, GIS engine, authentication architecture, or existing canonical data is replaced.
