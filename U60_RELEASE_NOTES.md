UI-only presentation upgrade built on the U59 known-good baseline.

- Premium command-center hero with portfolio pulse visualization using existing values.
- Hierarchical KPI strip with restrained motion.
- Interactive risk distribution hover state.
- Refined officer intervention queue with project click-through preserved.
- Refined immediate review list.
- Refined state risk chart using existing state-risk data.

- No backend API changes.
- No risk-engine changes.
- No predictive model changes.
- No GIS/data-source changes.
- No authentication/RBAC changes.
- No project data is bundled or fabricated.

The container environment did not complete `npm install` within the available execution window, so a local production Vite build could not be executed here. The release is therefore packaged without claiming a fresh build result. Run the supplied Windows validation commands before replacing the U59 working folder.
