# U71.10 final run

1. Stop the currently running BhoomiDrishti stack with Ctrl+C.
2. Extract this release into a new folder.
3. Run `npm install`. Do not run `npm audit fix --force`; it requests a breaking Vite upgrade.
4. Run `npm run preflight:local`.
5. Run `npm run build`.
6. Run `npm run start:all`.

The first backend start applies migration 018. It soft-archives the two known local validation fixtures named `BHOOMIDRISHTI_SINGLE_PROJECT_TEST` and `BHOOMIDRISHTI_PROJECT_IMPORT_SINGLE_TEST`, so they disappear from the active map/portfolio without deleting their dependent history.

Administrator users get a `Remove` action in the Projects register and Risk Map. Removal is a recoverable archive, not a destructive database delete. Active project APIs, dashboards and predictive portfolio views exclude archived projects. Re-importing an archived project ID reactivates it.

Persistent database remains at `%LOCALAPPDATA%\BhoomiDrishti\data\bhoomidrishti.sqlite`. Do not delete/reset it.
