# U72.4 SAFE MERGE GUIDE

Base: U72.3 Multilingual Accuracy Hardened.

## Preserved
- React/Vite frontend architecture
- Express backend
- persistent SQLite store and existing migration history
- existing auth/session/RBAC model
- GIS/map integrity and approximate-location safeguards
- predictive engine / Predictive Lab / ML governance
- U72.1 OCR adapter and human-review architecture
- U72.2 multilingual extraction
- U72.3 Marathi regression behavior
- canonical overwrite protection and provenance rules

## Added in one bulk step
1. Authority-scoped recoverable portfolio removal.
2. Responsible department/work-unit metadata on projects.
3. `projects:archive` permission separated from ordinary project editing.
4. Department Officer removal/restore restricted to matching responsible department when configured, plus existing jurisdiction/project scope.
5. Mandatory audited removal reason.
6. Portfolio archive + restore panel in Project Risk Register.
7. Persistent intake field verification queue with Verify/Reject controls for `documents:verify` accounts.
8. Multilingual regression fixtures for Marathi, Hindi, Tamil and Bengali.

## Data safety
- Project removal is a soft archive only.
- No project/evidence/history tables are dropped.
- Migration 019 is additive.
- Existing active projects remain active; `responsible_department` is nullable so existing records are not reclassified.
- No model artifact is replaced or promoted.
- Test language fixtures are controlled strings, not government records.

## Windows validation
From the project directory:

```powershell
npm.cmd install --no-audit --no-fund
npm.cmd run smoke:u72-document-intelligence
npm.cmd run smoke:u72.2-multilingual
npm.cmd run smoke:u72.3-regression
npm.cmd run smoke:u72.4-governance
npm.cmd run smoke:portfolio-hygiene
npm.cmd run smoke:frontend-symbols
npm.cmd run build
npm.cmd run start:all
```

Do not run `npm audit fix --force` because the existing Vite dependency range is intentionally kept stable.
