# BHOOMIDHRISHTI U75.1 — Full Integration Release

Version: `1.0.21-u75.1-full-integration`

## What is integrated

The U75.1 build extends the existing U75/U74 architecture rather than replacing it.

### Cross-module project flow

`Data Integration → validation → project matching → conflict review → approved promotion → project bootstrap → unified data snapshot → bulk feature initialization → existing risk/alert/operations/dashboard/project intelligence surfaces`

### Bulk intake

Supported intake formats:

- CSV
- TSV
- JSON
- NDJSON
- XLSX

Every upload is hashed and forensically analysed before governed promotion.

### Promotion safety

- Administrator workflow permission required.
- Dataset validation is required before promotion preview/promotion.
- Existing project matches are resolved through the existing entity-resolution logic.
- Conflicting non-empty fields are surfaced and blocked.
- Existing non-empty project values are not silently overwritten.
- New projects receive a canonical project ID through the existing project repository.
- Promoted projects run through project lifecycle bootstrap, unified snapshot refresh, and bulk feature initialization.
- Audit records are written for promoted projects.
- Predictive production model promotion remains separately governed.

### GIS integration

The existing Leaflet GIS module is preserved and extended with project-to-map focus navigation.

The map keeps the existing safeguards for:

- India geographic bounds
- coordinate validation
- exact/project-point provenance
- approximate location classification
- unresolved-location withholding
- parcel/source geometry
- risk zones
- project search
- state/risk/type/ongoing filters
- map refresh
- India view
- fit-to-data
- tile fallback
- location resolution
- project popup → project dossier
- project dossier → focused GIS map

No random coordinates are generated by U75.1.

## Important data boundary

The release does not include or replace the user's persistent production database.

No destructive database reset, seed, drop, truncate, or replacement operation is included in this release.
